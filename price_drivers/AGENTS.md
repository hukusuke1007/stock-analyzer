# AGENTS.md

東証プライムの企業について、直近3ヶ月の株価がなぜ動いたのかを調べて記録するディレクトリ。
AI エージェントがこのディレクトリでレポートを書くときのルール。`CLAUDE.md` はこのファイルへのシンボリックリンク。
アプリのコードとは独立しており、ビルドや型チェックの対象ではない。

## 置き方

- 企業ごとに `証券コード_企業名/` のディレクトリを作る(例: `7203_トヨタ自動車/`)
- レポートは `YYYY-MM-DD_3ヶ月の株価変動要因.md` とする。日付は調査した日
- 同じ企業を後日もう一度調べたら、前のファイルは消さずに新しい日付のファイルを足す

## レポートの書き方

- 株価は Yahoo Finance の日足(chart API)の終値で、日経平均と比べる。期間・基準日・出典 URL を必ず書く
- 前日比の絶対値が大きい日を上から拾い、その日の理由をニュース・適時開示で特定する。理由が特定できない日は「特定できず」と書き、推測で埋めない
- 理由ごとに、企業固有の材料か、相場全体・業種全体の動きかを分ける(日経平均・業種と同じ方向に同じくらい動いた日は相場要因とみなす)
- 文章は stock_investment リポジトリの `.claude/skills/japanese-tech-writing/SKILL.md` に従う

## レポートの構成

1. 概要(期間の騰落率、日経平均との差、主な変動要因を3行程度)
2. 株価の推移(月末終値・高値・安値の表)
3. 大きく動いた日と理由(日付・終値・前日比・日経平均の前日比・理由・出典の表)
4. 変動要因の分析(企業固有 / 業種 / 相場全体に分けて、どれがどれだけ株価を動かしたか)
5. 今後の注目点(次回決算日などのイベントと、株価を動かしうる材料)
6. 出典
